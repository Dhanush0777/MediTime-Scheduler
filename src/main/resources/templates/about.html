About MediTime

Smart Medical Prescription Time Table & Sound Reminder System

Important Medical Safety Disclaimer

This application is a prescription scheduling and reminder system, not a medical decision-making system. Medication schedules shown by this application are strictly based on the entered prescription. The system does not diagnose diseases, recommend medications, or alter dosages without explicit physician instructions. Always consult a qualified healthcare provider before initiating, modifying, or terminating any drug therapy.

System Objectives

Non-adherence to prescribed medication schedules is one of the leading causes of preventable medical complications and treatment failures globally.

  • Automated Conversion: Translates doctor prescriptions directly into daily chronological timetables.
  • Audible Alarms: Synthesizes real-time browser audio notifications via the Web Audio API without depending on flaky external audio assets.
  • Patient Accountability: Tracks exact taken timestamps, snooze intervals (5, 10, 15 min), and missed doses.
  • Adherence Tracking: Calculates daily and longitudinal compliance rates: Adherence % = (Taken / Total Scheduled) × 100.
Technology Architecture
Backend: Java 17+, Spring Boot 3, Spring Data JPA, Hibernate, Maven
Database: MySQL / H2 (Embedded Engine with MySQL Dialect)
Security: Spring Security, BCrypt Password Hashing, Role-Based Access
Audio Engine: JavaScript Web Audio API (Multi-Tone Synthesizer)
Frontend: HTML5, CSS3, Bootstrap 5, Font Awesome 6, JavaScript ES6+
